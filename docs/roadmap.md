# Roadmap – Schlemeier DMS / Finora

## Phase 1 – erledigt
- Finora v0.6.3-dev als reproduzierbarer Git-Stand
- CSV / CAMT / MT940 Normalisierung
- bestehende Matching-Engine
- gemeinsamer Integrations-Branch

## Phase 2 – aktuelle Integration
- Schlemeier-DMS-Projektstruktur
- gemeinsame Dokumentmodelle
- zentrale Firmen-/Privat-Zuordnung
- gemeinsamer Banktransaktionsvertrag
- Architektur dokumentieren

## Phase 3 – bestehende DMS-Seite übernehmen
- aktuellen Quellstand der veröffentlichten Schlemeier-DMS-Seite importieren
- vorhandene UI erhalten
- Dokumentkarten und Miniaturansicht anbinden
- "Wo gehört der Beleg hin?" an gemeinsames Datenmodell anschließen
- Status Neu / Prüfen / Zugeordnet / Abgelegt / Duplikat

## Phase 4 – Finora anbinden
- OCR-Vorschläge im DMS anzeigen
- bestätigte Änderungen an Finora zurückspielen
- Kontoabgleich in die DMS-Navigation integrieren
- Dubletten- und Prüfwarteschlange verbinden

## Phase 5 – v0.7
- Finanz-Dashboard
- Monatsaggregation
- Einnahmen/Ausgaben
- offene Rechnungen
- USt-relevante Monatswerte
- Abstimmungsstatus

## Freigabekriterium
Produktiv erst nach Tests mit echten, anonymisiert prüfbaren Bankformaten und einer vollständigen DMS-End-to-End-Prüfung.
