# Frontend

Dieser Ordner ist für die bestehende Schlemeier-DMS-Seite vorgesehen.

## Kernansichten

### Dokumente
- Tabellen- oder Kartenansicht
- Miniaturansicht
- Dateiname
- Dokumenttyp
- Firma/Privatperson
- Datum
- Betrag
- Status

### Prüfen
- Dokumentvorschau
- OCR-Text
- Klassifikationsvorschlag von Finora
- Auswahl "Wo gehört der Beleg hin?"
- Bestätigen / Korrigieren

### Kontoabgleich
- Bankbuchungen
- Rechnungsvorschläge
- Teilzahlungen
- Sammelzahlungen
- manuelle Zuordnung
- Zuordnung lösen
