# Schlemeier DMS

Zentrale Oberfläche für den PSS-Dokumenten- und Buchhaltungsworkflow.

## Rollen im Gesamtprojekt

- **Schlemeier DMS** = Benutzeroberfläche, Prüfung, Suche, Zuordnung und Status.
- **Finora** = OCR, Dokumenterkennung, lernende Klassifikation, Bankimport und Matching.
- **shared/** = gemeinsame Verträge und Datenmodelle zwischen beiden Modulen.

## Geplante Hauptnavigation

1. Dokumente
2. Prüfen
3. Kontoabgleich
4. Buchhaltung
5. Finanz-Dashboard

## Dokumentenworkflow

Eingang → OCR → Klassifikationsvorschlag → Prüfung → Zuordnung → Ablage → Nachvollziehbarer Status
