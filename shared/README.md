# Shared Contracts

Gemeinsame Schnittstelle zwischen Finora und Schlemeier DMS.

## Bereiche

- document-models/: Dokumentmetadaten und DMS-Status
- classification-rules/: Firmen- und Privatzuordnung
- bank-transactions/: normalisierte Banktransaktionen

## Regel

Neue Felder werden zuerst hier definiert und anschließend in Finora und DMS implementiert.
So vermeiden wir zwei inkompatible Datenmodelle.
